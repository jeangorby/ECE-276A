# Project 3

## Code Structure

The code for this project is organized into the following files:

### `localization.py`

### `feature_detection.py`

### `landmark_mapping.py`

### `SLAM.py`

## Running the Code

Note that each of these functions can be ran individually and will run the code related to its subpart in the project. The organization above shows the order it was revealed in the project document. 

python __.py

will run each individual section. If the dataset number wants to be changed, there is a variable for each code that can be changed for this purpose.
